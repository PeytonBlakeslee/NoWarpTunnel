# No Warp Tunnel v1.0.0

Skips the warp-tunnel presentation during Borderlands 2 travel. It does not change destinations or save files and has no extra options.

## Install or update

1. Close the game and back up your existing `sdk_mods/NoWarpTunnel/` folder and SDK settings.
2. Extract the matching **Player ZIP** into `Borderlands 2/sdk_mods/`, replacing the old mod folder and removing duplicates.
3. Confirm `sdk_mods/NoWarpTunnel/__init__.py`, restart the game, and enable **No Warp Tunnel** in the SDK Mods menu.

To uninstall, disable the mod, close the game, and remove its folder. Restore your backup to roll back.

## Compatibility and help

Windows Borderlands 2 is the Player target. The Pre-Sequel is experimental and untested; co-op and Proton/Wine are unverified; native Linux BL2 is unsupported by this package. A Loader change may persist after disabling until the game updates or replaces that actor.

For troubleshooting and issue reporting, see the [No Warp Tunnel user guide](https://github.com/PeytonBlakeslee/NoWarpTunnel/blob/main/docs/USER_GUIDE.md).
